# Abhay Jaiswal — Portfolio

Modern React portfolio focused on Java backend engineering, distributed systems, and production reliability.

## Highlights

- Recruiter-focused project case studies with architecture and outcome context
- Current experience, measurable impact, awards, and technical toolkit
- Shareable engineering blog with dedicated article routes
- Responsive and accessible technical design
- Direct email and GitHub contact paths

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The application uses `HashRouter`, so project and blog links remain shareable on static hosting without server rewrite configuration.
